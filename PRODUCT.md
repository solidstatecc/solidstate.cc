# Product

## Register

product

## Users

Operators and developers who run AI agents (Claude Code, Cowork, OpenClaw, NemoClaw, Antigravity). They arrive to browse, evaluate, and install agent skills. Context: mid-task, technical, allergic to hype. The job: find a skill they can trust, install it in one command, leave.

## Product Purpose

solidstate.cc is a curated AI agent skills marketplace. Honest directory: real provenance, real licenses, no fabricated install counts. Success = a visitor installs a skill or submits one. Curation over scale.

## Brand Personality

Stark. Compressed. Calm. Monochrome black/white identity, JetBrains Mono uppercase labels, Inter body. The voice is Jack Butcher contrast pairs + Karpathy build-from-scratch + Naval calm leverage. Median 9-word sentences. Show the artifact, then explain.

## Anti-references

- SaaS gradient-and-glassmorphism landing pages.
- Crypto-hype marketplaces (fake counters, FOMO badges, neon).
- Buzzword copy: streamline, empower, supercharge, seamless, game-changer (full banned list in `__Solid State/solidstate.md`).
- Decorative motion, orchestrated page loads.

## Design Principles

1. The directory is the design. Density and scannability beat decoration.
2. Monochrome carries the brand. Hierarchy through weight, scale, and spacing, never hue.
3. Earned trust: real data, visible provenance, honest empty states.
4. One command to install. Every page ends in a copyable artifact.
5. Disappear into the task. No element should ask to be noticed.

## Accessibility & Inclusion

WCAG 2.1 AA. Muted text ≥4.5:1 against its background (already enforced in globals.css comments). Visible focus rings, skip link present. Reduced motion respected for any future animation. Both themes must hold the same contrast floor.
